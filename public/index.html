Scheda virtuale nel browser

    
Il tuo progetto CubeIDE viene compilato qui nella pagina (clang in WebAssembly) con una HAL simulata: GPIO, interrupt EXTI, timer (anche PWM), UART, ADC, SysTick e priorità NVIC. Nessun server: i progetti restano in questo browser, sotto il tuo nome utente.

    
    
      
  1. ＋ Nuovo crea un progetto vuoto per la NUCLEO-F401RE (LD2, B1 e seriale già pronti): scrivi il codice tra USER CODE BEGIN e END.
    2. 
      
  2. 📁 Cartella: la cartella del progetto CubeIDE (quella con il file .ioc) o un intero workspace (scegli tu quali progetti). 🗜 Zip: uno zip del progetto, anche fatto su Windows. Bastano anche solo i file .c/.h con il .ioc: gli header della HAL li mette il sito.
    3. 
      
  3. Premi ▶ Avvia. La prima volta si scarica il compilatore (poi resta in cache e funziona anche senza Internet).
    4. 
      
  4. Nel Codice modifichi i file (più file aperti a schede, 🔍 o Ctrl/⌘+F per cercare) e con Salva e avvia o Ctrl/⌘+S ricompili. Gli errori sono sottolineati in rosso: clicca l'errore in alto per andare alla riga.
    5. 
      
  5. ⬇ Tutti scarica uno zip con tutti i tuoi progetti (⬇ Zip solo quello scelto): caricalo su un altro computer con 🗜 Zip.
    6. 
    

    
Interagire

    
    
      
  • Tieni premuto il pulsante blu B1 (o il tasto B), il nero è RESET.
    • 
      
  • Nella scheda Pin trovi un pulsante per ogni ingresso, un LED per ogni uscita, un cursore per ogni canale ADC. Sotto la scheda i Dispositivi (display, encoder, pulsanti, motori…).
    • 
    

    
Limiti del prototipo: gli interrupt partono nei punti in cui il programma consuma tempo (cicli while/for, HAL_Delay, HAL_GetTick), non a metà di un'istruzione; niente debug passo passo e niente scheda Variabili per ora. Micro supportati: STM32F401 e STM32F411 (header HAL STM32Cube F4 V1.28.3).
